# Mayur Mahajan Portfolio

This repository contains a personal developer portfolio website for Mayur Mahajan. It includes two versions of the portfolio layout: a main landing page and a separate `Portfolio` section with polished sections, animations, and responsive navigation.

## Project Structure

- `portfolio.html` — Main portfolio landing page.
- `portfolio.css` — Main page styles.
- `portfolio.js` — JavaScript interactions for typing animation, hamburger menu, smooth scrolling, active nav states, contact form handling, and reveal animations.


## Features

- Responsive navigation bar with mobile hamburger menu.
- Hero section with typing animation and CTA buttons.
- About section with education and location details.
- Skills section with progress bars.
- Project showcase cards.
- Experience and certifications sections.
- Contact form support with basic validation.
- Smooth scroll behavior and active section highlighting.
- Scroll reveal animations for improved visual polish.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Open `portfolio.html` in your browser to view the main personal portfolio page.
2. Customize the text, links, projects, and styles to match your personal branding.

## Notes

- Both portfolio versions are static and can be hosted on any static web host.
- The contact form is currently handled with client-side JavaScript and displays a confirmation alert.
